# Font Files

Place the font files in this directory:

## Avant Garde for Salesforce (Display/Headlines)

- `AvantGardeForSalesforce-Light.woff2`
- `AvantGardeForSalesforce-Light.woff`
- `AvantGardeForSalesforce-Regular.woff2`
- `AvantGardeForSalesforce-Regular.woff`
- `AvantGardeForSalesforce-Medium.woff2`
- `AvantGardeForSalesforce-Medium.woff`
- `AvantGardeForSalesforce-Bold.woff2`
- `AvantGardeForSalesforce-Bold.woff`

## Salesforce Sans (Header/Navigation UI)

- `SalesforceSans-Regular.woff2`
- `SalesforceSans-Regular.woff`
- `SalesforceSans-Bold.woff2`
- `SalesforceSans-Bold.woff`

Download from: https://github.com/nickshanks/Salesforce-Sans

## Fallback

If these fonts are not available, the system will automatically fall back to system fonts.

## Typography Usage

- **Display/Headlines**: Uses "Avant Garde for Salesforce" with `font-display` class
- **Header/Navigation**: Uses "Salesforce Sans" with `--font-header` variable
- **Body Text**: Uses Poppins for readability
- **UI Elements**: Uses Poppins for consistency
